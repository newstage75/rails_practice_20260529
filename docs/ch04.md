## 4.2 文字列とメソッド

### 文字列の式展開（string interpolation）

```ruby
first_name = "Michael"
"#{first_name} Hartl"        # => "Michael Hartl"
first_name + " " + "Hartl"   # => "Michael Hartl"（+ で結合してもよい）
```

- ダブルクォート `" "` の中の `#{ }` は **中身が展開される**。
- シングルクォート `' '` は **展開しない**（`'#{foo}'` => `"\#{foo}"` のように文字そのまま）。

### ⭐️ 画面出力 と 戻り値 の違い（重要）

| | 画面出力 | 戻り値 |
|---|---|---|
| 何 | 人間に**見せる**ために文字を画面に書く | 式が**値として持つ結果** |
| 例 | `puts`, `print`, `p` | `+`, `reverse`, `nil?` など全部 |

```ruby
x = puts "hello"   # 画面に hello と出る
# hello
x                  # => nil   ← 画面の "hello" ではなく、puts の戻り値 nil が入る
```

- `puts` / `print` は **画面に出すだけ、戻り値は `nil`**。
- 戻り値は変数に入れたり次の計算に渡せる（`y = 1 + 2` → `y` は `3`）。

### puts / print / p の使い分け

| メソッド | 用途 | 特徴 |
|---|---|---|
| `puts` | ユーザーに見せる | 末尾に改行。配列は1要素ずつ改行 |
| `print` | 見せる（改行なし） | `puts` の改行なし版 |
| `p` | **デバッグ用** | 中身を正確に表示。値をそのまま返す |

```ruby
puts "ab\ncd"   # \n を改行として解釈 → 2行で表示
p    "ab\ncd"   # => "ab\ncd"  クォートも \n もそのまま見える
p "foo"         # "foo" を表示しつつ、戻り値も "foo"（puts は nil）
```

- `p nil` は `nil` と表示される → 「空文字なのか nil なのか」を見分けられる（デバッグ向き）。

### 論理値メソッド（末尾 `?` の慣習）

```ruby
"foobar".empty?   # => false
"".empty?         # => true
"".nil?           # => false
nil.nil?          # => true
```

- `true` / `false` を返すメソッドは末尾に `?` を付ける慣習。

### if / elsif / unless と後置 if

```ruby
if s.nil?
  "nil"
elsif s.empty?
  "empty"
elsif s.include?("foo")
  "includes foo"
end

puts "x is not empty" if !x.empty?   # 後置 if（条件が真のときだけ実行）
puts "Both empty" if x.empty? && y.empty?
```

- `&&`（AND）/ `||`（OR）/ `!`（NOT）。

### メソッドチェーン

```ruby
nil.empty?       # NoMethodError（nil は empty? を持たない）
nil.to_s.empty?  # => true  （nil → "" に変換してから empty?）
```

### メソッド定義（暗黙の戻り値）

```ruby
def string_message(str = '')
  return "It's an empty string!" if str.empty?
  "The string is nonempty."   # ← 最後の式は return なしでも返る（暗黙の戻り値）
end
```

- 引数のデフォルト値 `str = ''` を指定できる。

### 演習: 回文（palindrome）

```ruby
# リスト4.8 後置 if で判定
s = "racecar"
puts "It's a palindrome!" if s == s.reverse   # "onomatopoeia" だと何も出ない

# リスト4.9 メソッド化
def palindrome_tester(s)
  if s == s.reverse
    puts "It's a palindrome!"
  else
    puts "It's not a palindrome."
  end
end

palindrome_tester("racecar")        # 画面: It's a palindrome!
palindrome_tester("racecar").nil?   # 画面: It's a palindrome! / 戻り値: => true
```

- `.nil?` が `true` になるのは、メソッドが内部で `puts` してるだけ＝**戻り値が `nil`** だから。
  （= 画面出力と戻り値の違いの実例）

## 4.3 他のデータ構造

### 配列（split / join）

```ruby
"A man, a plan".split(',')   # => ["A man", " a plan"]  カンマで分割（空白は残る）
"foo bar  baz".split         # => ["foo", "bar", "baz"]  引数なしは空白区切り
a.join                       # 連結 "A man a plan ..."
a.join('-')                  # 区切り文字を挟んで連結
```

- `split` ↔ `join` は逆の関係。
- `"foobar".split('')` で **1文字ずつ** バラせる。

### 添字・範囲オブジェクト

```ruby
a = ('a'..'z').to_a   # 範囲オブジェクト → 配列（to_a を忘れない）
a[6]    # => "g"   7番目（0始まり）
a[-7]   # => "t"   後ろから7番目（マイナスは後ろから）
a.first # a.last # a.length # a.last(7)
```

### ブロック（each / map）

```ruby
# 演習: 0..16 の各要素の2乗を出力
(0..16).each { |i| puts i**2 }   # ** は累乗

# 演習: yeller（連結して大文字に）
def yeller(s)
  s.map(&:upcase).join   # map { |c| c.upcase }.join と同じ
end
yeller(['o', 'l', 'd'])  # => "OLD"

# 演習: 文字列シャッフル（リスト4.11）
def string_shuffle(s)
  s.split('').shuffle.join   # 1文字ずつ → シャッフル → 連結
end
string_shuffle("foobar")     # => "oabfor"（毎回変わる）
```

- `{ |i| ... }` がブロック。`map(&:upcase)` の `&:` は `{ |c| c.upcase }` の省略形。

### ハッシュ（Hash） ＝ Python の dict 的なもの

```ruby
user = { "name" => "Michael" }   # 文字列キー（古い書き方）
user = { :name => "Michael" }    # シンボルキー（ハッシュロケット）
user = { name: "Michael" }       # シンボルキー（モダン・Railsで主流）

user[:name]    # => "Michael"   シンボルで取り出す
user["name"]   # => nil         文字列 "name" は別キー扱い！
```

- **`name:` で入れたら `[:name]` で取る**（文字列とシンボルは別物）。
- 繰り返し:
  ```ruby
  user.each { |key, value| puts "#{key}: #{value}" }
  ```
- ネスト（params の形）:
  ```ruby
  params = { user: { name: "Michael" } }
  params[:user][:name]   # => "Michael"
  ```

### シンボル（Symbol）

- `:name` のように先頭にコロン。文字列より軽量・変化しない「名前ラベル」。
- 最初は「クォートの代わりにコロンが付いた、キー専用の文字列」と捉えてOK。
- 変換: `"name".to_sym` => `:name` / `:name.to_s` => `"name"`
- Rails で頻出: `validates :name, presence: true` の `:name` も `presence: true`（= `{ :presence => true }`）もシンボル。

### inspect

```ruby
(1..5).to_a.inspect        # => "[1, 2, 3, 4, 5]"  中身を表す「文字列」を返す
puts (1..5).to_a.inspect   # [1, 2, 3, 4, 5]
p (1..5).to_a              # p = puts + inspect（ただし値もそのまま返す）
```

| 書き方 | 表示 | 戻り値 |
|---|---|---|
| `puts arr` | 1要素ずつ改行 | nil |
| `puts arr.inspect` | `[1, 2, 3, 4, 5]` | nil |
| `p arr` | `[1, 2, 3, 4, 5]` | 配列そのもの |

## 用語メモ: 「ハッシュ」は2つの意味がある

| | データ構造の Hash | ハッシュ値 / ハッシュ関数 |
|---|---|---|
| 何 | キー→値の入れ物（今やったやつ） | データの「指紋」文字列（SHA-256, bcrypt 等） |
| 用途 | データ管理・高速検索 | パスワード保存、改ざん検知 |
| 例 | `{ name: "Michael" }` | `password_digest`（第6章） |

- どちらも「ハッシュ関数」が起源（データを刻んで対応づける）。
- 第6章の「パスワードをハッシュ化して保存（digest）」、第9章の「記憶ダイジェスト」は**ハッシュ値**の話。
- 暗号化（鍵で元に戻せる）とハッシュ化（**一方通行・戻せない**）は別物。パスワードはハッシュ化する。

## 4.2.4 full_title ヘルパー（再訪）

`app/helpers/application_helper.rb`

```ruby
module ApplicationHelper

  # ページごとの完全なタイトルを返します。
  def full_title(page_title = '')          # 引数のデフォルトは空文字
    base_title = "Ruby on Rails Tutorial Sample App"
    if page_title.empty?                   # ページタイトルが空なら
      base_title                           #   ベースタイトルだけ返す
    else
      "#{page_title} | #{base_title}"      #   "ページ名 | ベース" を返す
    end
  end
end
```

- ここまでで学んだ要素の総動員: デフォルト引数 / `empty?` / `if-else` の暗黙の戻り値 / 式展開。
- **モジュール（module）**: 関連メソッドをまとめる仕組み。`include` で読み込む（ミックスイン）。
  Rails はヘルパーモジュールを自動で読み込むので、`full_title` は全ビューでそのまま使える。
